2. 主页面证据与材料
标题：证据与材料
每行：材料名称（普通文字）｜状态（只读）｜[查看]
次行：实际提供人 / 形成时间，或样例数量 / 办理轮次；不重复长正文。
例：原始问题与结论依据｜风险成立｜[查看]

例：补件记录｜补件已完成｜[查看]

补件 [查看] 只打开该补件详情，不再误开整个案件材料集合。

3. 关联工单 / 事项详情弹窗
标题：工单详情 / 申诉详情 / 整改详情 / 补件详情 / 问题详情 [X]
关联阅读有前序对象时：[返回上一项]
主题、编号 [复制]、实际当前状态
基础信息：工单来源（适用时）、坐席、业务、来源通话 [查看]、指标 [查看依据]、实际负责人和完成期限（存在时）
正文按对象显示：
- 工单：核查范围 / 已提交核查说明（有值时）→ 问题清单与意见 → 证据摘要；无问题工单显示范围核查结果。
- 申诉：理由、核查说明、裁定结果、原结论依据和相关材料。
- 整改：目标、完成标准、资料要求、轮次、提交材料和验收意见。
- 补件：要求、执行人、截止、已提交材料、接收 / 结束结果。
- 问题：命中证据、判断结果、已形成的分发要求或撤销依据。
不显示办理概览、处理记录、关联事项页签，不铺开整条业务链，不显示办理动作。
已关联的短材料正文在本弹窗直接展示，不再生成“证据与材料 → 预览 → 正文”的重复层级；长音频/规则仍允许专门查看。
底部：[关闭]；查阅不改 URL、底页筛选、页签和滚动。完整处理历史仍在主页面的处理记录中阅读。

4. 命中规则弹窗
标题：命中规则 [X]
只有从问题详情进入时保留 [返回问题详情]；直接从规则入口打开时不显示等同于关闭的“返回问题列表”。
规则名称、规则编号、指标、适用业务（只读）
判断参数：仅实际检测时保存的参数和适用条件；规则无独立参数时省略空参数区。
业务依据：检测时引用的资源名称及字段内容；角色 / 例外只在已记录时显示，空值不造“未记录例外条件”占位块。
没有可靠命中条目标识时保留被引用的完整依据，不能靠文字猜测后任意删掉规则条目。
移除配置方式、编辑与保存提示、CSV 模板、资源管理说明、版本号；保留历史依据读取，不能换成当前配置。
关联问题编号、检测批次归入次要元信息。
底部：[关闭]。
