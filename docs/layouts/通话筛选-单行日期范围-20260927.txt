6001 通话记录筛选条
目标：桌面端所有通话筛选控件同排，日期用一个范围选择器。
布局：搜索 → 业务 → 日期范围 → 坐席 → 班组 → 检测状态 → 重置 → 导出。移除筛选展开按钮与第二行高级筛选容器。
桌面搜索框适度收窄，日期范围保留完整起止日期；可用宽度不足时自然换行，不隐藏条件。
日期范围弹层：中文日历，可跨月；先选开始日期、再选结束日期，反向选择自动排序，同一天可选。
日期选择先暂存，[应用]同时更新原 startDate/endDate 并回到第一页；[取消]、Escape、点外部均丢弃本次选择。[清除]清空两个日期。
未选完整区间不能应用；再次打开显示当前值。保留现有筛选数据口径、坐席权限、导出及重置逻辑。
通话页不再显示独立“已筛选”标签行，当前条件直接在筛选控件中展示；日期弹层清除或重置筛选可清空范围。无数据沿用原空态。
窄屏搜索独占一行，日期范围可以独占一行，其余控件自然换行；弹层不超出视口。
评审：通过。以单个范围控件替换重复日期字段，可在常规桌面宽度承载全部条件，无需展开额外区域。
验收：通过。相关组件 ESLint、TypeScript、Next 生产构建及 git diff --check 通过。
1440px / 内容区 1160px 下，无筛选与出现重置按钮时全部控件均在同一行，导出靠右；390px 下自然换行，日历在视口内，无横向溢出。
实际操作：9/28 至 10/3 跨月应用正确；9/25 再选 9/20 自动排序；同日可应用；只选开始日期时应用禁用；取消保持原值；清除同时移除两端日期；检测状态筛选和重置正常。9/20–9/25 筛选实际得到 30 条记录。
日期范围依旧沿用通话结束时间（未结束取开始时间）的本地日期筛选规则，未修改业务数据。
后续精简验收：通话列表独立已筛选行已移除；实际应用日期后该行不存在，范围仍显示在控件中，筛选结果和重置正常。
