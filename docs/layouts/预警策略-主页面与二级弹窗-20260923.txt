6001 预警策略：主页面及二级弹窗
流程：b2b-page-txt-refine；本轮替代此前同页面的布局说明。

目标与核对
操作者：质检主管维护共享预警策略；其他有查看权限的角色只读。
对象：策略共享参数，以及指标规则的检测结果与策略的关联。
实页：主页面已有双栏和居中弹窗，但新增重复三次解释配置内容；各组帮助文字挤压实际控件；关联摘要与选择卡片重复显示；“特征/检测结果”称呼混用；新增关闭焦点未显式恢复。
数据：保留现有配置字段、默认值、可选关联和原子保存校验。规则特有参数仍归规则；不新增改名、版本、发布流程。

主页面 TXT
[指标规则] [预警策略]                         [字段说明]
搜索策略名称或编号 | 风险等级 | 共 N 项       [新增预警策略]
左侧 策略列表：名称 → 范围 → 触发 → 处置 → 关联规则数。
右侧 策略详情：策略编号 / 名称 / 状态 / 更新时间。
  策略配置                                 [查看策略] [配置策略]
  检测范围：角色、阶段、条件范围
  触发条件：方式、次数/窗口或时长
  风险与处置：等级、动作、接收对象、重复提醒间隔
  不重复呈现指标编号 6.3.4；不展示可能与当前参数不符的固定动作说明。
  关联指标规则 N 条                         [管理关联]
  表格：规则名称 | 关联指标 | 检测结果（含原有规则特定阈值）
  行间分隔，最后一行无下分割线。

新增 / 编辑弹窗 TXT
标题：新增预警策略 / 编辑预警策略                       [X]
副标题：新增说明可暂不关联；编辑显示策略名称。
新增：策略名称 * [输入，最多100字]；编辑不新增改名能力。
检测范围
  检测角色：[坐席 / 客户 / 双方]
  检测阶段：[全程 / 开场 / 服务中 / 结束]
  开场、结束：阶段范围 [1–3600] 秒；注明开始后/结束前。
  服务中：服务中起点（开始后）[0–3600] 秒；服务中终点（结束前）[0–3600] 秒。
触发条件
  触发方式：[单次命中 / 累计次数 / 持续时长]
  累计：累计次数 [2–1000] 次；统计窗口 [整通通话 / 最近1分钟 / 最近5分钟 / 自定义时长]
  自定义统计窗口：[1–86400] 秒，仅累计且自定义时显示。
  持续：持续时长 [1–3600] 秒。
  按规则分别统计，任一满足触发；只保留这项影响理解的简短说明。
风险与处置
  风险等级：[高风险 / 中风险 / 低风险]（保持原默认值）
  处置动作：[通知] [通话中提醒] [进入人工复核]，多选且至少一项。
  接收对象：[所属主管 / 质检一组 / 质检二组]。
  仅选通话中提醒：当前坐席（只读，固定值不伪装为选择器）。
  包含通话中提醒时：提示仅用于实时通话、发送当前坐席；其他动作使用所选接收对象。
  重复提醒间隔：[每通话仅一次 / 1分钟 / 5分钟 / 自定义时长]
  自定义提醒间隔：[1–86400] 秒。
关联指标规则（仅新增或原有尚未配置对象，可选）
  复用下方关联选择结构，不弹第三层、不行内展开。
底部固定：简短保存影响说明；错误/放弃确认；右侧 [取消] [保存策略]。
  新增无关联：提示可保存后通过管理关联补充。
  编辑：影响当前关联的 N 条规则后续检测；历史检测结果保留。

查看策略弹窗
标题 查看预警策略；副标题为策略名称。
正文与主页面同顺序完整显示参数；只读字段不带必填星号。
当前关联 N 条指标规则的提示，不复制一遍关联长表。
底部 [关闭] [编辑策略]（仅有权限显示）；查看转编辑同层切换，始终只有一个弹窗。

管理关联弹窗
标题 管理关联；副标题为策略名称。
说明：勾选检测结果使用本策略，保留已有的其他策略关联。
指标筛选 | 搜索规则或检测结果
已选 N 条规则 · M 项检测结果                [仅看已选（复选）]
选择列表（不再另列重复的已选摘要卡片）：
  规则名称 / 关联指标 | [ ] 检测结果 [ ] 检测结果
  不适配选项禁用并注明原因；已选但不兼容项允许取消。
  语速等特定参数只读提示。
每条规则一行，可含多项结果；无外框套卡，仅行间分隔，末行无底线。
底部固定：影响说明 / 错误；[取消] [保存关联]。
移除最后策略关联仍由既有校验阻止，不把缺关联自动当作不预警。

交互与边界
所有配置按钮在对应标题右侧；新增在筛选栏右侧。
取消直接关闭、丢弃输入并恢复准确入口焦点；X/Escape 未改直接关闭，已改在当前弹窗底部确认，保持正文不跳动。
保存成功关闭并刷新当前对象；失败保留输入。新增成功选中新策略，原有保存/并发/权限校验保留。
空列表可重置筛选；仅看已选但无选择时说明如何返回全部。筛选不删除隐藏的已选项。
字段有条件显示，不出现无效字段；数值限制保留。底页保留筛选、选中和滚动。
桌面弹窗统一约800px，正文单一区域滚动；窄屏单列，弹窗不超视口，取消保存始终可达。

实施与验收
- 主页面：策略编号不再附带技术指标编号；说明不预设某个接收人/动作。新增、查看、配置、管理关联仍是明确按钮打开居中弹窗；字段说明为策略专用内容。
- 新增：初始焦点进入名称；空名称提交显示必填错误。修改参数及关联后取消关闭，重开名称为空、关联清空，焦点返回新增按钮。
- 条件字段：累计次数显示次数与窗口；自定义统计窗口显示秒数；持续模式显示时长并隐藏累计字段。声纹在持续模式下显示触发方式不适用。
- 处置：只选通话中提醒，接收对象为当前坐席只读；风险选择显示高风险/中风险/低风险。
