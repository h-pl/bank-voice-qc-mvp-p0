# 转写滚动与标题精简

- 去掉录音和转写重复标题，段数、命中数量和定位保留。录音状态异常仍准确提示，无障碍区域名称保留。
- 原实现转写本身没有滚动，外层详情可滚动。本轮将桌面单一告警证据详情的滚动交给转写，播放器及定位栏固定在正文上部。
- 只在桌面且正文唯一子区域为告警证据时启用；混合材料、弹窗、窄屏继续外层滚动，避免遮住其他内容。没有改业务记录。

验证：1440×800滚轮使转写scrollTop从0变为225，最后00:32段完整可见，播放器位置不变。键盘PageDown、定位16秒、播放最后片段自动滚动均实际检查。1728×900及1280×720独立滚动；1024×768及390×844使用外层滚动，各视口无水平溢出。

TypeScript、相关组件ESLint、生产构建通过。用户内嵌浏览器两个现有标签处于其他角色/事项，未修改其身份与业务数据；滚动验收使用独立浏览器的相同本地路由。
