# 质检工作台减法设计
目标：三角色日常处理、证据核对与资源维护；首屏直接进入业务，不承担产品介绍。
色彩：画布 #F6F7F8、内容面 #FFFFFF、正文 #171717、次文字 #687078、细线 #E5E5E5、强调 #B75717。风险/成功沿原语义色。
字体：沿用系统中文字体；唯一页面名在顶栏 14px/600，事项标题 19px/600，正文13px，辅助12px；报表数字27px，不把列表计数做展示型大卡。
布局：
侧栏（品牌/机构/模块/重置与版本） | 顶部路径、身份与通知
                               | 页签 + 筛选 + 小型逾期信息
                               | 对象列表 | 事项/证据 | 办理动作
规则/资源：列表内放查询和入口，右侧保留完整参数/资源内容。
报表：筛选、摘要、图表、明细保持；取消摘要装饰点、重复点击文案和反复示例标记。
评审：不新增风格型 hero、不更换品牌、不藏筛选或当前动作；不靠字号缩小塞入内容；移除重复结构本身。列表/详情重复事项名用于定位，予以保留；统计口径、版本/依据、错误/等待责任人属于必要信息，保留。
动效：高频浏览即时；按钮不缩放，结果提示只做200ms opacity；原键盘和减少动态效果策略保留。
