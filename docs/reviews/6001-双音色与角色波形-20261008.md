# 双音色对话与角色波形

使用本机macOS say合成，坐席Tingting、客户Meijia。通过同一句文本实测确认两个声音输出不同：Tingting 4.093秒，Meijia 3.932秒；此前Eddy/Reed中文别名与Tingting输出PCM完全相同，原因并非前端混音。

保持现行与旧版五段原话和0/8/16/24/32秒起点，录音40秒。两份新音频使用独立文件名，避免旧缓存。每段语音生成时校验长度不超过下一段起点。波形从新WAV计算160个峰值。

波形坐席蓝灰、客户暖棕；已播放区域在各自色系加深。映射按转写时间与角色，不进行声纹识别；没有说话人信息的区间保留中性灰。

验证：生产构建、TypeScript、ESLint及7项录音回归通过。新旧WAV按8秒切段比较，坐席片段保持，客户两段均改变。浏览器实际加载新音频，元数据40秒，点击客户原话定位8秒且保持暂停；五个区间的普通/已播放波形均按agent/customer交替着色。未重置浏览器数据或修改业务记录；未主张已人工试听。
