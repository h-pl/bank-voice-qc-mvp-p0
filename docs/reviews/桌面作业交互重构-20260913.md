# 桌面作业交互重构

目标：5001 质检 MVP。按用户反馈恢复原配色，重点改任务组织、材料预览、首屏操作与筛选反馈，不以手机适配为主要目标。

## 实现

风险、工单、申诉整改和通话详情采用同一 CaseShell：案件摘要与材料入口在中间，当前责任、下一步操作、最近处理在右侧顶部。队列、正文、责任栏独立滚动，整页不被长证据撑高。录音、转写、判断依据与完整材料通过原生 Modal 预览。所有已有材料字段和业务动作保留。

通话列表增加可展开筛选、活动条件计数与可单独移除的标签。规则指标目录移入指标旁 info；参数保持就地展开。趋势点增加有边界限制的 callout，环图和条形图补充分类反馈；点击仍进入实际明细。

## 实测

- 1440×900 桌面：工单与申诉案件、责任栏 top 均为约 234px；所有主要与次要业务按钮均在首屏，页面高度等于视口高度，无需滚动整页寻找操作。
- 工单证据及完整材料入口前置；证据弹窗实际宽度 1060px，内部可滚动。Escape 后回到“预览录音与证据”并保持外页 scrollY=0。
- 通话筛选“失败”后得到 1 条；收起条件面板仍显示“失败”标签，单独移除恢复未筛选结果。
- 趋势首个数据点 callout 显示日期、数量与点击提示，位置保持在图表边界内；方向键切换、Escape 关闭正常。
- 规则列表不再出现“16 项指标目录”按钮；指标说明 info 打开完整目录，关闭回原位置。
- 独立的 127.0.0.1 演示数据：坐席暂停整改仍可预览标准和材料，只保留允许的材料动作，无验收通过或结案；质检员仍可处理被分派的核查工单。
- 原业务 57 项回归及 MVP 验收通过；类型、ESLint、生产构建通过；Premium strict audit 无问题。

不改变 lib/workflow.ts，不改变历史证据快照与三角色权限。修改已加载到本地 5001；此次新改动未提交或推送，之前的备份 tag 仍保留。
