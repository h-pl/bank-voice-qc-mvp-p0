# 配置表单 UI 实施与验收

2026-09-23，按用户最新确认修订。原“策略选择指标特征”实现已由本轮替换。

## 已实现

- 指标卡片补齐实际名称、版本、资源、条件与策略摘要、草稿及待完善状态；策略卡片补齐等级、动作、接收对象、提醒间隔及关联数量。
- 特征、角色、阶段、阈值和策略绑定在指标页配置；策略仅维护共用处置。
- 明确区分待配置与不预警；多档独立判断，拦截重复档和不预警冲突；抢话不支持持续时长。
- 保留各资源专属维护入口；语音识别与纠错无预警设置。
- 保存、检查、发布、取消、草稿对比与历史只读接入现有流程。
- V6 迁移只追加版本，保留已有草稿、历史和批次；策略发布更新关联指标引用快照。

## 验证

- TypeScript 与生产构建通过；100 项工作流回归测试覆盖迁移、条件归属、能力约束、待配置拦截、引用版本传播、资源变化、权限和并发。

- 验证草稿已放弃，未将验收用阈值发布为生效配置。
- 浏览器：策略编辑仅有风险处置字段；历史 V2 保留旧版检测范围与触发条件，无编辑按钮；规则与策略卡片展示真实数据。
