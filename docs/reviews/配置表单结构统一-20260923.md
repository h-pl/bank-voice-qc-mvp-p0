# 指标配置表单结构统一

按截图对应的 6001 实现，统一所有指标规则的共用详情与预警编辑弹窗。

- 详情顺序：检查内容、业务依据、预警配置、版本记录。
- 检查内容：关联指标、适用业务、检查目标、检查项目、判断边界、检测输出。
- 业务依据：引用资源、资源版本、引用范围；继续读取当前所查看的规则快照。
- 预警配置：检测结果和预警策略；策略下分别列出检测范围、触发条件、风险等级、处置方式、接收对象、重复提醒间隔。详情与编辑使用同一个只读组件，自定义间隔展示具体秒数。
- 声纹的三种结果、关键词的命中结果及其他指标特有参数保留；未配置、不预警、不适用分别表达。历史字段缺失不套用当前定义。
- 沿用白色详情表面与原字号，固定标签宽度、长内容换行，窄屏单列并保留字段标签。

验证：TypeScript 和四个相关组件 ESLint 通过；28 项现有策略配置、目录和关联回归通过。浏览器检查声纹/关键词详情及弹窗、390px 弹窗和详情（无横向溢出）、取消后焦点返回配置入口、历史版本只读。未修改用户持久化业务数据。

本轮为本地 UI 调整，未提交、推送、部署或同步飞书。工程源码位于质检-ui-6001，未修改旧版语音质检-银行。
