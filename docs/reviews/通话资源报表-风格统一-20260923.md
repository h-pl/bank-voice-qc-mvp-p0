# 通话记录、业务资源、质量报表风格统一

依据：用户指定复核工单2为视觉基线；沿用其灰色画布、独立白色区域、12px圆角、16px间隔、暖橙选中态及现有字体。未重置数据，未发布规则、修改资源或提交业务动作。

## 实现

- 通话记录：页签与筛选移到画布上，结果表及分页独立承托；详情抽屉区分录音/处理记录/关联事项与通话信息/可用操作。窄屏上下排列，关闭入口固定可达。
- 业务资源：共用语义页签，类型、状态、搜索合并筛选；资源表、内容说明与分页独立白区；详情内容、引用与影响、版本历史按主分区排列。
- 四个质量报表：筛选外置，摘要与图表分开，左右分析区以灰色间隔区分，明细全宽；保留数据口径、日期、图表选中、钻取、导出及权限。
- 仅清理本次涉及的示例操作及辅助文案，不改变检测命令逻辑；授权样例等具有实际业务含义的字段保留。
