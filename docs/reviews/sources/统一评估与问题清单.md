## 四、产品演示规则与未来交付参数

以下关于是否存在某条业务路径的决定可继续评审；天数、样本数和容量可用演示值，原型不需要先取得客户合同或真实验收证据。先前额外建议的高风险会签不是既有要求，已撤回默认限制：

1. 哪些已确认风险允许“无需整改”，谁审批、必须提供哪些理由？建议由主管依据项目清单决定，高风险是否需专家会签另行冻结。
2. 正式申诉窗口、补件期限及 SLA 冻结从提交还是受理起算？当前设计保留申诉中冻结要求，需明确每个时间点及重复申诉策略。
3. 真实整改效果复测需要多少新通话、哪些风险切片、多久观察？样本不足时建议保持待验证，不自动用模拟录音通过。
4. 16 项各自采用哪个正式标准方法、客户门槛、样本量和置信区间？负责人和冻结记录应逐项明确，规则页隐藏项仍保留登记。
5. 实际通话负载、保留期、目标硬件和容量档位是什么？未冻结前，资源估算维持待验证。
