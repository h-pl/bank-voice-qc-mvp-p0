# 16 项指标与规则配置及验收

> 2026-09-12 范围澄清：当前交付物为高保真原型，模拟数据、预设结果与前端状态均可使用。本文涉及真实模型、后端、客户验收及容量实测的内容为未来交付参考，不作为本轮原型完成条件；当前仅检查页面、交互、业务流转与示例一致性。

本文件统一当前指标口径，来源为历版 PRD、指标归类与评测方案，以及运行时目录 [official-indicators.ts](../../lib/official-indicators.ts)。它不声明任何一项已通过客户验收。

## 1. 总目录与页面分工

完整指标为 **16 项**，按“AI 核心技术支持能力 / 业务服务能力”两个维度及四个类型组织。规则配置仅展示其中 **10 类**：4 类检测/处置条件和 6 类业务规则。其余 **6 项仍保留在测试集、评测与交付目录**，由 3 项能力服务和 3 项平台验收承接。

“AI 核心 6 项 + 业务服务 10 项”与“可配置规则 10 类 + 非规则 6 项”是两种不同划分。研发报告的“完整支持 10 项”又是静态实现分级，三个数字不能互换。

## 2. 标准来源与内部补充

官方目录中的名称为《自然语言处理技术及产品评估方法 第6部分：客服质检系统》，编号 YD/T 4394.6—2023。旧文档中的其他标准名称应停止沿用。[国家标准信息公共服务平台目录](https://std.samr.gov.cn/hb/search/stdHBDetailed?id=07911622B0C17E8CE06397BE0A0ACE21)记录发布日期为 2023-07-28、实施日期为 2023-11-01。

此前核对的本地 PDF 封面为报批稿；它可用于理解指标，但不能直接当成已核验的正式发布全文。正式验收前须核对发布文本及客户合同中的方法、条款和门槛。详细证据见[三文档评审](重要资料三文档评审_20260910.md)。

六个内部能力层只用于研发归责，不能替代上述官方目录。音量、响应、挂机等扩展检测也不增加或减少这 16 项。旧文档的“双 95”、95%/98%、P95 ≤ 2 秒等数字属于历史候选口径，未有双方冻结记录前不作为当前验收承诺。

## 3. 每项验收必须固定的内容

逐项登记指标、被测对象（规则/服务/平台流程）、场景与适用范围、正类定义、评测单位、样本来源、标注/仲裁责任人、冻结集版本、Prediction 版本、计算方法、门槛来源、运行证据、问题与复验结果。

分类检测须保留 TP/FP/FN/TN、样本数与置信区间；多分类按类别和关键切片分别出结果。平台功能验收使用任务日志或功能用例，不强行生成分类金标。分母为零、样本不足、任务失败或结果未知时显示不可判定/待补齐，不能算通过或正确阴性。

- 声纹 FAR/FRR 必须明确分母是异人/同人试验数还是其他协议定义；两种口径不可混报。注册与测试集避免同源泄漏。
- ASR 的长度分层边界应互斥且覆盖目标范围，并保留方言、噪声、长通话与双声道切片；纠错另测误改，不能只看召回。
- 情绪和消极情感按客户/坐席、情绪类别、长通话后段、短语音和否定语境分别检查，不能用单个 angry 二分类成绩代表全部能力。
- 覆盖率以约定应处理清单为分母，同时披露失败、重试、漏跑和未完成；抽检任务须记录抽样范围与比例。
- 时效性分实时与离线，明确定义计时起止、失败及超时处理。单模型段级耗时不能代表告警可见时间。
- 专业性用有版本的业务依据与专家仲裁，关键事实错误单独阻断；隐私检测与脱敏保护分别验证。
- 数据展示核对字段、统计、钻取、导出/API 和访问范围；风险干预检查动作及送达闭环，不能只验一次状态修改。

一条规则的主指标负责 Gold、门槛、责任人与计分，关联指标用于筛选和影响分析。每项仍独立验收，不能把同一命中在多个关联指标中重复加分来提高总成绩。

## 4. 数据与发布门禁

客户真实脱敏数据为主，公开数据辅助，合成数据用于补盲。按通话、主体及必要时间边界隔离训练、开发和验收集；冻结后被测服务产生 Prediction，独立标注产生 Gold。人工复核结果先作为候选样本，经独立校对/仲裁才能进入金标。

发布页始终保留 16 项登记状态，分别显示准备度、实现证据、已计算与验收结果。不能只对“已经冻结门槛的少数项”算通过率，再暗示完整体系通过。单项确实不适用时需要明确的项目范围及双方记录，仍保留该项与理由；规则页不显示某项不是不适用依据。

当前代码使用构造样例，现有演示状态是 **0/16、发布阻断**；这只是已实现页面的状态描述，不是原型必须始终阻断的要求。可按演示场景预设通过、未通过和待评测等结果，保证汇总与明细一致即可。正式交付阶段才需要独立金标、真实模型及环境证据。

## 5. 已消除的旧口径冲突

| 历史说法 | 当前口径 |
| --- | --- |
| 规则配置应列出全部 16 项，否则缺能力 | 规则展示 10 类，完整能力与验收保留 16 项 |
| 意图识别是服务，因此不出现在规则配置 | 意图由服务实现，同时属于可配置规则条件 |
| 六个内部能力层可以替代验收主目录 | 仅供内部归责，验收逐项保留 16 项 |
| 有实现/有页面/已计算即可标通过 | 静态证据、运行结果、客户验收分别记录 |
| 指标截图应承担完整公式和发布门槛 | 截图表达定位；完整口径由本专题和评测模块承接 |

运行时指标名称与映射继续集中在 `lib/official-indicators.ts`。后续实现应核对表中语义，不能为迁就旧页面再创建第二份指标目录。
