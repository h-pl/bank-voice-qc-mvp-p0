# 新版与旧版：UI 交互对比与采纳方案

日期：2026-09-20。新版＝5001，旧版＝5002 V4.11。用户明确要求保留原配色，重点改善交互、信息层级和桌面操作效率，不以响应式改造代替任务。

| 页面／交互 | 新版 | 旧版 | 采纳方案 |
| --- | --- | --- | --- |
| 整体层级 | 紧凑，部分卡片嵌套 | 分区鲜明但说明重复 | 灰白橙原配色，减少容器，通过标题间距分隔 |
| 页名 | 顶栏单一页名 | 大标题说明及操作占正文 | 紧凑标题与页级动作，案件名优先 |
| 工作台 | 无统一入口 | 概览全面，流程介绍占空间 | 待办、超时、重点变化，直接定位对象 |
| 作业布局 | 队列、详情、责任统一 | 多工单方案并存 | 共用框架，中间按业务组织不同内容 |
| 队列 | 编号问题坐席状态紧凑 | 当前处理人和剩余时间明确 | 标题为主，责任期限其次，编号弱化，橙色选中 |
| 分类 | 状态页签命名不一 | 类型和待办分散 | 待我处理／进行中／已结束／全部；类型独立筛选 |
| 筛选 | 展开条件与可移除标签 | 部分更多筛选不可用 | 常用常显，收起保留标签和计数，一键重置 |
| 滚动 | 独立滚动但固定区挤正文 | 长页面操作下沉 | 队列与详情滚动，主操作可见，历史不挤操作 |
| 责任栏 | 责任期限明确 | 当前、下一节点和等待对象完整 | 增加当前任务和提交去向，明确等待对象 |
| 动作按钮 | 主次明确但数量较多 | 配解释但文字长 | 一个主动作，常用次动作可见，低频动作归组 |
| 案件摘要 | 简洁，部分只剩编号 | 原结论目标标准更业务化 | 回答发生什么、当前结论、争议目标、需要做什么 |
| 材料 | 弹窗减少滚动，入口笼统 | 材料名称摘要状态清晰 | 具体材料清单＋宽预览弹窗，名称摘要状态版本 |
| 录音转写 | 当前案件内预览 | 业务关联表达清楚 | 从问题定位片段，保留回听转写依据与关闭恢复 |
| 历史关联 | 页签收纳 | 时间线直观但占空间 | 最近关键事件常显，完整历史在页签 |
| 规则详情 | 当前值范围版本清楚 | 业务边界充分，顶部限制说明太重 | 保留新版，补业务含义，目录制度放 info |
| 参数编辑 | 就地展开可对照原值 | 弹窗字段完整但遮上下文 | 少量就地，多项集中表单，保存差异、发布影响 |
| 资源列表 | 目录详情不便比较 | 分类表格比较版本负责人状态 | 分类表格入口，宽抽屉预览，独立详情编辑，恢复列表位置 |
| 版本引用 | 历史版本关系连贯 | 状态明显但部分仅反馈 | 沿用新版，显示差异和引用切换的可检查结果 |
| 图表 callout | 提示与明细联动已实现 | 管理指标好、交互弱 | 保留新版，日期数值分母，点击筛明细，可清除 |
| 报表布局 | 维度完整但密集 | 重点突出偏展示 | 少量核心指标、趋势分布、明细；口径就近 info |
| 空态异常 | 有恢复提示，默认期间可无样例 | 内容充实但有展示按钮 | 原因和具体恢复动作；保存导出必须有可检查结果 |

## 容器使用规范

| 任务 | 容器 | 行为 |
| --- | --- | --- |
| 指标术语口径 | info／轻量浮层 | 就近出现，不占主操作区 |
| 少量参数 | 就地展开 | 原值范围影响，取消恢复，未保存保护 |
| 资源摘要与引用 | 侧边抽屉 | 列表状态保留，关闭恢复触发焦点 |
| 原音转写证据 | 宽弹窗 | 问题定位，关闭恢复案件位置 |
| 长知识与 SOP 编辑 | 独立详情 | 编辑空间与草稿，返回恢复列表 |
| 发布、改判、终止 | 确认对话框 | 具体对象、差异与影响，不使用空泛确认 |

## 首轮实施重点

业务资源分类表格；具体材料清单与状态；责任栏提交去向；压缩作业重复层级。新增工作台聚合现有真实演示状态，不编造经营数据。规则参数继续就地编辑，录音继续宽弹窗。

## 验收

列表→预览→关闭／详情→返回保留筛选位置；新建草稿→检查→发布资源→规则引用确认完整可走；过期表单和权限校验仍有效；主操作不被长材料推出首屏；键盘 Esc/焦点、空结果、原型失败与重复提交按共享契约验证。桌面优先，一档窄屏仅作为必要可用性检查。
