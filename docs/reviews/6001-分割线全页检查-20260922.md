## 共享组件修正

- `--divider-subtle: #edf0f3` 作为内容分隔色；轮廓与控件描边仍保留原有层级。
- 通话 Sheet 的标题与页签不再叠加横线；页签组与正文只保留一条边界。
- 通知列表仅相邻条目之间加线，标题和最后条目不加底线。
- 处理表单的意见组、处置字段、底部按钮用间距分隔；证据选项和材料表去除末行底线。
- 报表 CSS 原样式也同步更新，避免按需加载顺序重新覆盖共享规则。
- 表格表头选择器提高到与旧工作区样式一致的作用范围，实际颜色为 rgb(237, 240, 243)。
