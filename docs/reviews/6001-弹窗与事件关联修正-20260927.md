# 6001 弹窗与事件关联修正


## 2026-09-27 弹窗、版本信息与事件关联修正

按用户截图反馈：弹窗和通话抽屉打开时焦点先落在容器，不自动聚焦编号复制按钮并弹出提示；主动悬停或键盘聚焦仍可查看完整编号与复制反馈，关闭恢复触发入口焦点。

办理页面、问题/依据详情、表单、处理记录与通知不展示内部版本号，也不提供依据版本切换；历史结果按时间与办理轮次阅读，当前事项仍关联其真实原始依据。底层快照、并发检查、申诉原结论关系和审计记录保留，避免文案修改影响业务逻辑。

处理记录逐条展示其实际所属事项及关联问题，编号复制和查看分开；当前事项的查看返回概览，关联问题打开详情，其他事项定位对应办理页，通话记录采用相同方式。关联基于实体关系并按权限过滤，不仅凭同一通话或文本中的编号生成入口；完全相同的操作与结论记录合并展示。暂无记录显示明确空态。
