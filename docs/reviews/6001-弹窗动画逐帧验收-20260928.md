

## 2026-09-28 弹窗切换动画逐帧修复

逐帧复现：父层虽已标记 covered，默认 transition:all 200ms 导致 visibility 延迟隐藏，进入二级前约 200ms 仍可见两层；父遮罩立即隐藏，但子遮罩从 opacity 0 重新淡入，背景短暂闪亮。首次打开的弹窗位置尺寸稳定，无需修改其居中布局。

修复：共享 Modal 关闭通用 transition，层级遮盖立即生效；对子层内容和遮罩标记 nested，禁止再次淡入，保持 opacity 1。首次打开保留原淡入，层级间立即替换；减少动态效果偏好下关闭弹窗与遮罩动画。

逐帧复验：桌面进入判断依据、返回、65ms 间隔快速三次往返，以及390px窄屏进入检测记录、返回，共116帧；每一帧可见弹窗数为1、遮罩数为1，层级切换期间透明度始终1，各层自身位置尺寸无漂移。真实点击与Esc返回后焦点恢复查看判断依据。构建、类型检查、lint、git diff --check 通过。本地6001运行新构建，未部署线上。
