# 6001 shadcn 迁移与页面去重

本轮对应用户“先把能替换成 shadcn 的组件替换，再逐条按修改意见调整”。范围为本地 6001，不包含线上发布。

| 修改项 | 本轮结果 |
| --- | --- |
| 通用组件统一 | 按钮、表单输入、下拉、复选框、表格、页签、徽标、弹窗、抽屉、折叠、规则多选及音频滑块使用 shadcn |
| 处理记录重复 | 直接显示时间线；去掉内层标题卡、说明、计数及场景载入事件 |
| 导航重复 | 删除顶栏专注办理与逐条导航；队列头折叠，队列底分页 |
| 待办和通知重复 | 模块保留待我处理，顶栏 Popover 只显示事件通知 |
| 详情信息重复 | 来源通话/指标集中到元数据；期限集中到责任区；移除空材料区和重复检查范围 |
| 通话查看详情 | 编号打开 Sheet，内含录音与证据、处理记录、关联事项；移除查看详情专列 |
| 预警首屏与提醒 | 展示命中片段和通话状态；提醒内容优先，后续复核按需展开 |

## 验证记录

- 类型检查、lint、69 项业务流程测试及 Next.js 生产构建通过。
- 浏览器验证：信用卡筛选第 2 页打开 CALL-1024，Escape 关闭后仍为第 2 页，焦点恢复到原编号。
- 通知弹层仅含事件；提醒表单的可选复核展开正常，取消后返回触发按钮。
- 复核结论中展开证据，勾选后已选数从 1 更新为 2；取消未提交业务结论。
- 新增资源保留 CSV 模板/导入入口，关联规则搜索多选正常展开。
- 1280×720 检查预警布局和报表；页面无横向溢出，报表绘图区无新增横向滚动容器，浏览器控制台未发现警告/错误。

保留边界：文件选择器、日期日历仍由浏览器提供底层能力；图表、时间线及音频数据逻辑保留业务实现，不以不适用的通用组件替代。
