# MVP-P0 v0.2.1 UI 交互优化与验收

本轮针对用户指出的规则参数编辑割裂、列表下堆叠详情，以及常用操作隐藏问题实施。只在 `/Users/hpl/Desktop/语音B端产品/质检-mvp-p0` 修改，运行于 5001；保持高保真原型、三角色七模块、16 项指标与 10 类规则。原项目和旧标签保持独立。

## 已落实的修改

| 问题 | 当前交互 | 验收要点 |
| --- | --- | --- |
| 规则列表、详情与编辑入口相隔过远 | 左侧检索和选择，右侧完整详情；参数配置紧接标题 | 选中项与详情对应；固定规则有明确只读解释 |
| 参数只有值，缺少完整修改语境 | 原位展示当前值、单位、范围、业务作用、修改原因、保存与取消 | 静默阈值 3–60 秒整数；业务范围和提醒触发使用明确选项 |
| 草稿与生效关系不直观 | 新旧值对照 → 检查草稿 → 发布新版本 | 草稿不直接生效；发布后历史 V1 保持原值；历史版没有编辑入口 |
| 编辑中切换造成输入丢失 | 就近提示先保存或取消，保留输入 | 模块导航、规则选择、历史版本及浏览器返回受保护 |
| 通话表格下继续堆叠详情 | 点击编号/查看详情进入独立详情；可返回列表、切换上一通/下一通 | 返回保留业务筛选与第 2 页，详情打开位于页首 |
| 通话中被标为“当前责任已办结” | 通话显示真实通话状态、检测状态、时长和班组 | 不把无处理人等同已办结；候选与确认成立数量分别标注 |
| 判断依据隐藏且证据字号小 | 原话、判断依据、引用资源快照直接展示，提高正文和动作字号 | 有候选的通话直接显示依据；无候选不伪造命中规则 |
| 资源维护缺少明确落点 | 编辑入口邻近内容，新资源保存后自动定位 | 新增表单显示“新资源草稿”，保存按钮写明“保存草稿” |
| 队列翻页后详情仍指向旧页（N05） | 清除旧焦点，选择本页首条 | 选中编号、详情编号与动作目标一致 |
| 日期倒置被当作空结果（N06） | 就近报错并禁止导出，可交换日期 | 调整后恢复查询；普通零结果仍保留空状态 |
| 弹窗与窄屏行为不一致 | 原生 dialog；窄屏列表/详情切换；明显返回按钮 | Tab/Shift+Tab 留在弹窗、Escape 关闭后焦点回原按钮 |

仅开放原有三类参数，不新增规则搭建器或模型配置。业务资源的内容编辑保持完整表单。检测批次、历史整改轮次属于追溯信息，可按需展开；常用动作、筛选、参数编辑和判断依据直接展示。

## 四项 skill 的落地

- **frontend-design**：保留当前浅灰、白色、黑色和橙色风格。以“当前对象及其操作”组织页面，删除重复概念横幅，设置稳定的正文、说明与标题层级；实际查看桌面与手机截图后修正字号、留白和返回入口。
- **web-design-guidelines**：按当次获取的 [Vercel Web Interface Guidelines](https://raw.githubusercontent.com/vercel-labs/web-interface-guidelines/main/command.md) 检查标签、语义链接、焦点、就近错误、空状态、只读状态、响应布局和动态效果。以下追踪是已修复位置，不表示产品全部组合路径均无问题。
- **vercel-react-best-practices**：编辑差异从状态派生；切换处理放在事件内；ActionForm 按需加载；React Activity 保留已访问模块筛选并停止隐藏效果；编辑器初始值与版本绑定当前对象。
- **animate**：高频导航、记录与证据不做动效；Feedback 仅用于指针按压 120ms 和操作提示 200ms。CSS 只改变 transform/opacity，强 ease-out 为 `cubic-bezier(0.23, 1, 0.32, 1)`；键盘操作不附加动效，减少动态效果设置取消位移并保留轻量透明度提示。未增加动画库。
