# 6001 统一设计与样例数据验收

本轮按 b2b-ui-design 的页面目的、信息层级、组件契约和实际浏览器验证执行；最终选中态遵循用户最新的橙色圆角色块要求。

## 已实施

- 全局橙色圆角选中态；无页签下划线和队列左侧短线。
- 队列紧凑四行信息结构，规则与事项列表复用。
- 资源查看改为滚动抽屉；列表直接编辑、删除；引用删除保护。
- 关联事项去重复标题、分离状态，修正材料条目留白。
- 跨模块详情与列表分类同步；窄屏详情优先，操作区位于其后。
- 增量样例：8 通通话/8 个问题、4 张工单、6 项资源和关联日志。

## 实际验证范围

- 1280×720：风险预警、复核工单、申诉与整改、通话、规则、资源及四个报表模块的主页面检查。
- 1920×1080：规则、风险预警桌面布局检查。
- 1440×1000：最新圆角色块、关联事项列表、资源 Sheet；验证 Sheet 正文确实滚动，关闭后恢复列表。
- 900×900：复核详情先于责任区、无页面横向溢出。
- AP-1033 关联事项进入 WO-D-8：自动选择已结束分类及对应工单；没有空材料占位。
- 类型、lint、工作流及新增样例/删除保护测试用于验证变更；此次没有发布部署，也没有验证每个身份下的全部业务操作。
