# 七页设计语言统一与布局修复

## 已实施

- 七页统一公共颜色、面板、分区标题、控件、导航与选中状态。语义色保留于风险、证据和分析数据。
- `.ui-tabs` 统一作业、详情、通知与报表页签，保留 ARIA、方向键、Home/End 和焦点。
- 报表变量、图表颜色、面板圆角、筛选高度与明细表接入公共系统；通话表格采用相同的表头与行节奏。
- 预警、工单与通话详情的责任和操作分区使用一致标题层级；申诉整改仍使用更完整的责任、期限与日志布局。
- 申诉详情跨行操作栏不再撑高标题行。标题行使用 max-content；三个页签不随正文长短上下跳动。
- 关联事项的标题与计数按实际可见条目产生；空状态使用符合该业务的说明。
