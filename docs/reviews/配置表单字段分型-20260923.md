# 指标规则与预警策略：字段与页面设计

2026-09-23 用户纠正并要求使用 b2b-ui-design。此版替代此前“全部触发条件迁至指标”的设计。

| 对象 | 配置内容 |
| --- | --- |
| 指标规则 | 引用资源、特有参数、特征 → 已发布预警策略的关联 |
| 预警策略 | 检测角色、阶段及范围、触发方式、累计次数及窗口或持续时长、风险等级、处置动作、接收对象、重复提醒间隔 |

## 指标规则子页面

列表按 PRD 7.9.2 指标表的配置归属筛选，不将固定逻辑、阈值、词库、处置拆成互相重叠的类：

- 固定参数：关键词检出、服务礼仪、专业性、隐私性、禁用词、消极情感；没有指标特有参数，按检测结果关联预警策略。
- 可配参数：声纹识别、情绪识别、意图识别、语言表达；在指标中维护表内特有字段及策略关联。
- 无需预警：语音识别、文本纠错；仅维护引用资源。
- 预警配置：风险上报与干预，沿用独立“预警策略”子页面，不混入指标规则清单。

覆盖率、时效性、数据展示仍归任务或展示设置。筛选数量按实际规则条数统计，同一指标可有多条规则；顶部筛选与详情使用同一分类，卡片不重复展示分类。分类取决于指标配置职责，不随某条特征选择“不预警”而变化。

卡片展示真实规则名、关联指标，以及“资源”和“预警”两行；预警关联单行展示，多项以分号连接，溢出显示省略号，悬停及详情可看完整内容；编号仅保留在详情，卡片底部仅显示草稿/待完善等异常状态。关联指标标签置于标题右侧，使用 7.9 指标目录原名；适用业务留在详情只读展示，不显示右箭头；标题下不显示配置分类；无需预警的指标统一显示“预警　无”。规则版本只在详情显示；资源版本紧跟资源名称同行显示，不单独增加一行，多资源时逐一对应。移除卡片内规则版本号、默认生效状态、重复的无需预警说明和逐条不预警关联，完整内容在详情查看。

详情结构：返回列表 → 名称、状态、版本 → 指标说明 → 引用资源 → 特征与预警策略 → 待发布草稿 → 版本记录。

配置弹窗按特征组织。声纹有身份不匹配、未注册声纹、无法确认身份；情绪按标签；意图按已发布资源；语言表达有静默、抢话、语速过快、语速过慢。每项选择策略或明确不预警，待配置可存草稿但不能发布。语速阈值属于指标特有参数。选定策略后以浅灰摘要展示角色、阶段、触发条件和处置，无重复编辑入口。

固定结果指标按命中关联；服务礼仪按规范缺失关联。语音识别与文本纠错只维护资源，不配置预警。资源类型与字段仍按下表。

## 预警策略子页面

列表支持搜索及高/中/低风险筛选。卡片展示名称、编号、版本、完整触发摘要、风险及处置、接收对象、重复间隔、关联指标数量和草稿状态。

新建填写名称。详情与编辑共用三组字段：

1. 检测范围：角色、阶段；开场/结束秒数，服务中起止偏移按需显示。
2. 触发条件：单次、累计或持续；累计展开次数与统计窗口，自定义窗口补充秒数；持续展开时长。
3. 风险与处置：等级、动作、接收对象、重复提醒间隔及自定义秒数。

指标可复用同一策略，条件修改发布后统一生效。声纹仅支持坐席和全程；抢话等离散事件不支持持续时长。不兼容的关联在选择器中禁用并说明原因；策略编辑也校验已生效的关联，不能发布不相容条件。

## 保存、迁移与历史

草稿 → 检查 → 发布流程保持。策略发布追加版本并更新关联指标的策略引用快照；历史与进行中的检测不改写。

V7 迁移恢复通用条件在策略中的归属。V6 若同一策略曾被不同条件关联，按条件组合生成独立策略并保持各绑定原有含义，不擅自合并阈值。历史版本和旧草稿保留；旧草稿重新编辑时明确提示核对。没有重置用户进度。

浏览器界面按最终产品呈现。真实检测、通知和复核投递的服务接入状态仅在联调文档记录；本轮不声称其已接通。

业务分类及适用业务由后台预先制定并统一下发，指标规则详情仅展示适用业务，不提供客户侧新增、编辑或选择业务分类的入口。

## 就地关联与引用展示（2026-09-23）

指标规则侧按特征选择策略，预警策略侧在一个弹窗中按规则分组勾选特征。两个入口编辑同一份规则 bindings，不复制关联数据，不跳转页面、不重复选择当前策略。策略卡片按实际规则数统计引用。

策略侧保存只变更当前策略的关联，保留其他策略、指标特有参数及已有草稿。多规则保存为原子事务，校验策略及各规则版本；任何一项失败均不写入。取消最后一条策略关联时，该特征明确设为不预警。保存草稿后两侧可见，生效引用在规则检查、发布后更新；这两步可在当前策略页原位完成，并沿用原规则发布确认与完整差异核对。历史检测保持原快照。

已有规则关联编辑器仅可选择已发布策略；新策略可按下节保存待发布关联计划。不支持的规则不进入可选列表，规则内不兼容特征禁用。已有关联失效时可取消。参数仍由指标规则维护，策略关联弹窗只读显示语速等参数。筛选不清除选择，关闭未保存修改需明确放弃。

本轮供用户查看本地页面，飞书 PRD 尚未同步本次入口说明。

验收：类型检查、涉及文件 ESLint 和 127 项业务回归全部通过（含新增的 6 项关联测试）。浏览器验证同页多规则勾选、保存、检查与发布，双向编辑同步、保留其他策略、取消放弃、筛选保留选择、刷新恢复，以及 390px 窄屏和 Escape 焦点恢复。测试在独立上下文执行，未改变用户原有业务数据。

## 新增策略时选择关联范围

新增策略及未发布策略草稿中提供可选“关联范围”：先按指标筛选，再勾选具体规则的结果特征。指标仅作筛选，选择指标不会自动全选其下规则。跨指标切换保留选择，条件调整造成不兼容时保留已选项并提示处理。

策略内容与所选关联一并保存至策略草稿；此时不改写目标规则，规则侧通过同一草稿计划显示待发布关联。策略检查与发布均核对规则版本、已有草稿、特征兼容性和完整性。目标规则存在草稿则拒绝合并；版本变化需在策略编辑中明确重新核对，不能静默覆盖。一次发布原子生成策略版本及各目标规则的关联版本，失败不产生部分生效。成功后清除待发布计划，以规则的已发布 bindings 作为唯一生效来源，原有其他策略、参数、历史及进行中的检测不变。放弃新策略草稿不残留规则关联。

空关联仍可保存和发布，后续沿用原位管理关联。策略发布后，双方继续编辑同一份规则关联草稿。

验收（新增关联范围）：TypeScript、涉及组件 ESLint 与全部 133 项测试通过，含 6 项新增策略关联事务测试。浏览器完成跨指标勾选、保存、策略及两条规则一并检查发布、规则侧待发布与生效展示、刷新恢复、390px 无横向溢出。发布保留其他策略及历史；目标规则草稿或版本冲突阻止整次提交。浏览器验证使用独立上下文，未向用户数据加入测试策略。
