## 范围与剩余验证

当前仍是本地模拟数据原型，生产 UX 契约不代表已具备服务端权限、真实 ASR 或银行系统接入。敏感搜索词不写 URL，查询筛选沿用 Activity 的本次会话缓存，刷新恢复业务状态但筛选回默认。

未穷举全部业务弹窗、未做真实操作系统 IME 组合输入、全量屏幕阅读器、跨浏览器、强制色/减弱动画运行时矩阵；对应保护已在共享代码中实现。音频失败重试新增分支经静态检查，本轮未通过网络故障注入验证；真实网络异步/并发与会话失效不属于当前本地状态原型。

UI 成功/失败路径以以上浏览器操作和 57 项领域回归为证据，不声称完整 WCAG 审计或正式生产验收已通过。
