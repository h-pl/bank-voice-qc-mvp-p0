## 辅助操作与全部位置

| 位置 / 操作 | 允许条件与去向 | 不允许替代的主流程 |
| --- | --- | --- |
| 普通复核/抽检申请补证 | 质检员“申请补证” → 主管“安排补证” → 执行人提交 → 主管接收 → 原质检员继续 | 待分拣预警不直接“要求补充材料”；资料不足不能办结 |
| 期限与转派 | 仅核实中或允许管理的整改阶段，记录原因、期限与新责任人 | 主管确认/裁定阶段不靠延期或转派绕过确认/退回 |
| 调整整改要求 | 坐席申请 → 主管“调整目标与标准”，必要时重新核验 | 不等于主管直接判定通过或直接修改质检结论 |
| 撤回申诉 | 本坐席、未办结；撤销未完成核查和补件，保留历史，回原结果选择 | 不把撤回认定为接受；旧任务不得继续提交 |
| 规则优化反馈 | 自动误报归档后的独立反馈 | 不阻止归档，不直接发布规则 |
| 通话详情、问题证据、材料预览、关联事项 | 查询依据，或转到对象后按当前身份/状态显示动作 | 不恢复已关闭的历史动作；转派后新核验人应能打开材料样例 |
| 风险预警/复核/申诉整改侧栏与内嵌表单 | 使用相同上下文动作、标签及提交校验；草稿在编辑表单内保存 | 不显示“更多操作”折叠、不显示旧通用结果意见 |
| 策略、资源列表/详情/编辑/引用 | 当前配置按 TXT 方案直接保存，校验后原子更新后续检测引用 | 旧检查/发布/手动选版本命令不是当前按钮；历史批次不改写 |
| 报表钻取、通知、成功提示 | 打开实际对象，重新计算当前可见性、责任和阶段 | 不能因来自旧通知而获得旧阶段权限 |
