# 规则配置页：TXT 实施与验收（2026-09-23）

实际项目：质检-ui-6001。本轮按用户确认的“按钮弹窗，不要页面伸缩”修正规则配置交互；字段结构保留，配置版本管理全部为 P2。本轮未发布线上、未提交 Git，也未重置或保存修改用户的 localhost:6001 配置数据。

## 当前实施

- 页面统一为检查定义、业务依据、预警配置；保留各指标真实输出结果。
- 查看内容、编辑内容通过按钮打开居中 Dialog，取代资源侧边抽屉。默认定位当前规则引用条目，支持搜索和查看全部内容；直接展示共享引用范围，复用资源专属表单，保存后回到查看态。
- 配置预警通过按钮打开居中表单弹窗，底页保留摘要与配置按钮，不插入编辑区。支持多条独立关联，不兼容策略禁用并解释；移除最后关联回到待配置，不自动变为不预警。
- 查看策略按钮打开只读详情弹窗，替换展开/收起策略详情。配置预警弹窗内直接展示完整策略参数，不再套第二层详情弹窗。
- 所有弹窗正文内部滚动，标题与关闭、底部保存/取消保持可达。底页隔离交互，不因打开/关闭而伸缩；关闭恢复入口焦点，保留筛选、当前规则和滚动位置。
- 资源编辑与配置预警的“取消”直接放弃本次修改并关闭弹窗，不返回查看态、不二次确认；右上角关闭或 Escape 在有未保存修改时，在同一弹窗提供继续编辑/放弃修改。完整校验、原子保存、权限和并发控制沿用现有逻辑，失败保留输入。
- 资源管理、策略管理仍是明确的次级导航入口，提供来源返回。
- 当前配置界面不提供版本号、历史记录、版本切换、对比、回退、检查或发布入口；这些产品能力全部属于 P2。内部快照和案件处理历史保持兼容。

## 本轮验证

- TypeScript 与 6 个修改组件的 ESLint 检查通过。
- 直接保存、策略关联和配置的 28 项回归测试通过；本轮未重复全量构建。
- 6001 浏览器验证资源查看/编辑、预警配置与策略查看均打开居中 Dialog；规则详情内容高度打开前后均为 1101px，关闭后焦点返回原按钮。
- 预警移除最后关联后保存被校验阻止，输入保留；资源编辑与预警配置的未保存关闭均能提示并放弃，未写入 6001 配置数据。
- 390×844 窄屏预警弹窗宽 366px，页面宽 390px，无横向溢出；正文内部滚动，底部操作位于视口内。资源编辑入口在窄屏仍打开弹窗。测试后恢复桌面视口。

- 验收期间 6001 热更新曾停留在恢复工作区，重启开发服务后恢复正常；未修改业务代码或重置数据来绕过加载问题。
