# 录音与通话转写 UI 优化

日期：2026-10-08。范围：截图框出的共享录音与转写组件，主入口为风险预警 F-1030。

## 设计

保留灰白画布、黑色播放操作、浅橙证据与选中态，沿用系统中文字体及常规字重。播放器标题、来源状态和播放控制在宽面板内合并为一行；容器宽度不足 520px 时自动分为两行。波形、播放轴、命中范围继续按真实时间对齐。时间刻度、命中时间和角色标签调整为 12px，当前时间为 13px，转写正文保持 14px。宽 1440px 视口下播放器由约 194px 缩至 178px。

转写采用固定时间列、角色列、弹性正文列和定位状态列，悬浮或键盘聚焦时显示定位提示，已定位/播放中状态持续可见。提示行用色标说明命中片段，并说明点击原话可以定位录音。宽度不足 380px 时原话转至第二行；较窄播放器隐藏命中按钮的文字前缀以优先完整展示时间，读屏名称保持完整。

## 保留行为

点击原话、命中区域或键盘调整播放轴同步定位；暂停时不自动播放，播放时继续。保留音量、倍速、回退、吸顶、录音加载失败与重试、无录音时阅读原话。证据导航仍仅在存在视野外命中片段时显示；无新增业务动作、数据写入或外部接口。

## 本地验收

- 生产构建（包含 TypeScript）通过，修改组件 ESLint 通过。
- 录音时间轴及证据相关既有测试 6/6 通过。
- 实际页面：点击命中原话定位到 00:16 且保持暂停；播放/暂停、键盘进度、1.5 倍速和键盘音量控制通过。
- 1440、1280、1024、390px 视口检查；后三种视口页面、播放器和转写均无水平溢出。
- 模拟 audio error 事件后禁用播放并显示重试，转写仍可定位，重新加载成功。此项是 UI 错误分支验证，不代表已模拟全部网络故障。
- 页面数据沿用浏览器现有记录，不重置。CALL-1030 仍准确标示合成音频。
