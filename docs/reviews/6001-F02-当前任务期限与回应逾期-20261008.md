# F02：当前任务期限与回应逾期

日期：2026-10-08。状态：实现及本地验证完成，待用户核对；F03 及后续未启动。

## 问题与行为

已分发预警的预警处置时钟已经结束，但坐席回应仍是待办。原列表只取预警截止，导致正文已提示回应逾期，队列却漏计、筛选不到，责任区也不显示回应期限。

现统一当前任务期限：

| 当前阶段 | 使用期限 |
|---|---|
| 预警初审、预警处置 | 原初审或处置截止 |
| 已分发、待坐席回应 | 回应期限 |
| 接受后生成的整改任务 | 整改完成期限 |
| 申诉核查、主管裁定 | 当前核查或裁定期限 |
| 等待补件 | 补件期限 |
| 仅待知悉、已结束 | 无当前办理期限，不计当前逾期 |
| 申诉暂停整改 | 保留期限，显示暂停，不计当前逾期 |

列表截止、排序、逾期数量及筛选、责任区、预览、CSV 和回应提醒使用同一上下文。原预警时钟作为历史保留；已结束的回应任务不再因旧期限产生当前逾期。期限调整继续保留历史超限事实。沿用现有责任人、权限和操作入口。
