# 6001 UI 实际修复 · 2026-09-22

本轮直接修改 6001 本地项目，不是评估清单。保留已有未提交改动。

## 已实施

1. 规则目录显式采用纵向布局，编号不换行，去除每项重复的“全部业务”。
2. 资源筛选标签不收缩；复核结论字段改为标签在上、选择器在下。
3. 弹窗居中从 transform 拆到独立 translate；旧入场关键帧改为仅 opacity，避免从右下角跳到中间。
4. 资源列表移除重复大标题，新增按钮并入工具栏；名称直达详情，预览另设次级入口。
5. 自动候选来源仅显示于原始问题；复核工单头部显示问题数量，不取首个问题的指标或结论代表整单。
6. 待主管确认的复核意见明确标注；申诉理由只在摘要显示一次。
7. 暂停整改显示“已暂停 · 等待申诉裁定”，去掉重复暂停标签及错误的等待坐席提交提示。
8. 未形成结论的候选不显示空结论材料卡；尚未提交的整改材料、验收意见为静态状态，不再打开空预览。
