# 风险预警、申诉与整改、质检策略视觉统一

设计依据：用户提供的复核工单2截图，2026-09-23。

## 实施

- 风险预警和申诉与整改：移除包裹页签、筛选与三栏的大外框，保留浅灰画布上的三个独立白色分区。统一列表宽度、责任操作栏、标题、元信息、页签、间距、暖橙选中态和黑色主动作。
- 搜索及筛选留在分区外上方；队列改为滚动加载，保留全部结果数量和末尾加载状态。队列点击不再重置仍匹配当前记录的筛选。
- 申诉与整改保留事项类型、申诉理由、整改目标、暂停状态、材料与验收信息；调整期限/改派等操作放在“更多操作”内。风险等级和原办理流程保持不变。
- 质检策略：保留两栏；搜索、类别/风险筛选、数量、新增策略移到上方工具栏，左侧恢复紧凑规则列表；字体、页签、分区和状态与复核工单2一致。通用条件仍由预警策略统一维护。
- 复核工单2与两个办理页共享作用域样式，原复核工单和通话记录不使用新作用域；不引入宿主 main 的跨页面覆盖。

- 申诉/整改类型筛选、暂停整改、进行中整改和“更多操作”核对；390×844 风险及整改详情无横向溢出，办理栏顺排在详情下方。
